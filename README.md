## Club Event Poster (Webpage)

Description:
A static, responsive event poster webpage built with HTML and CSS. The design mimics a digital poster with a bold hero section, event details (title, tagline, date, time, venue), highlights (like DJ night, dance, competitions, food stalls), and a “Register Now” call-to-action button. The footer includes placeholder sponsor logos and social media icons.

Features:
	•	Clean HTML + CSS structure
	•	Responsive design (mobile & desktop)
	•	Dark theme with neon accents + glassmorphism cards
	•	Subtle hover/fade animations
	•	GitHub Pages/Netlify deploy-ready
